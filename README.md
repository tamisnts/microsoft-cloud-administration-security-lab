# Microsoft Cloud Administration & Security Lab

Laboratorio pratico de estudos com foco em administracao de nuvem Microsoft - Azure, Microsoft Entra ID e conceitos de Microsoft 365/Intune. Desenvolvido para aprofundar conhecimentos tecnicos em cloud computing, identidade, governanca e seguranca.

Este e um laboratorio pratico de estudos, construido para aprofundar conhecimentos em Azure, Microsoft Entra ID e administracao Microsoft Cloud. Nao representa experiencia profissional.

Os recursos sao criados, testados e documentados em ambiente pessoal de aprendizado, com uso consciente de creditos e tiers gratuitos (Azure for Students) quando disponiveis.

## Objetivo

Construir um laboratorio pratico que demonstre, de forma documentada e organizada, conhecimentos em administracao e seguranca de ambientes Microsoft Cloud - identidade, controle de acesso, redes, computacao, monitoramento, logs, governanca e automacao.

## Tecnologias e conceitos estudados

- Microsoft Azure (Resource Groups, VNet, Subnet, NSG, VM, Storage)
- Microsoft Entra ID (usuarios, grupos, RBAC, MFA/Security Defaults)
- Azure Monitor, Log Analytics e alertas
- Azure Policy e governanca de cloud
- PowerShell para administracao
- Microsoft 365 e Intune
- Conceitos de Blue Team / seguranca de identidade e cloud
